# APEX AI

A local AI assistant for Windows. It runs entirely on your own PC: no accounts, no
subscriptions, and nothing you type is sent to a cloud AI.

## Download

Go to **[Releases](https://github.com/Bladezx3/apex-ai-releases/releases/latest)** and download `APEX-AI-Setup-<version>.exe`,
then run it.

* Windows 10 or 11, 64-bit. A graphics card with 6 GB+ of video memory makes it much
  faster, but it isn't required.
* The first time it opens, APEX downloads its AI engine (about 1.5 GB) and an AI model
  that fits your PC (3–15 GB).
* Windows may say **"Windows protected your PC"** because the app isn't code-signed yet.
  Click **More info → Run anyway**.
* After that, APEX tells you when there's a new version (Settings → Updates). It only
  installs when you click.

## Safety

APEX asks before it changes anything on your PC. It never touches passwords, sign-in or
admin prompts, Windows Security or anti-cheat. **STOP AI** (Ctrl+Shift+X) halts
everything immediately.
